Privacy Policy — Recalm YouTube Ops Tool

Last updated: November 12, 2026

The Recalm YouTube Ops Tool (the "Tool") is an internal operations tool used exclusively by the owner of the Recalm YouTube channels (including Recalm Lab, Recalm Studio, Shiryokaramiru Rekishi, Gravity Lever, and Sim Arena). The Tool is not offered to the public, has no third-party users, and is not distributed to any other developer or service.

Use of YouTube API Services

The Tool uses YouTube API Services under the channel owner's own authorization. By using the Tool, the operator agrees to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). The Tool accesses and manages only the owner's own channels and videos: uploading the owner's original videos, editing their titles and descriptions, setting scheduled publication times, and reading the owner's own channel analytics.

Google Privacy Policy

Information accessed through Google APIs is handled in accordance with the Google Privacy Policy (https://policies.google.com/privacy).

Use and storage of data

Data obtained through YouTube API Services is used solely to operate the owner's own channels. It is stored only on the operator's own computers, protected by file permissions restricted to the operator. It is never sold, never shared with third parties, never transferred to other services, and never used for advertising or for building profiles of any person.

Revoking access

The Tool's access to the owner's Google account can be revoked at any time through Google's security settings page: https://security.google.com/settings/security/permissions

Data retention and deletion policy

API data is retained only while it is needed for channel operations and measurement. The operator deletes stored credentials and data immediately upon request or when they are no longer needed. Because the Tool's only user is the channel owner, any deletion request can be sent to the contact below and is carried out by the operator without delay.
