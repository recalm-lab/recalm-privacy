Privacy Policy — Recalm YouTube Ops Tool

Last updated: November 12, 2026

The Recalm YouTube Ops Tool (the "Tool") is an internal operations tool used exclusively by the owner of the Recalm YouTube channels (including Recalm Lab, Recalm Studio, Shiryokaramiru Rekishi, Gravity Lever, and Sim Arena). The Tool is not offered to the public, has no third-party users, and is not distributed to any other developer or service.

Data accessed

Using YouTube API Services under the channel owner's own authorization, the Tool accesses and manages only the owner's own channels and videos: uploading the owner's original videos, editing their titles and descriptions, setting scheduled publication times, and reading the owner's own channel analytics.

Use and storage

Data obtained through YouTube API Services is used solely to operate the owner's own channels. It is stored only on the operator's own computers, protected by file permissions restricted to the operator. It is never sold, never shared with third parties, never transferred to other services, and never used for advertising or for building profiles of any person.

Data retention and deletion

API data is retained only while it is needed for channel operations and measurement. Stored credentials and data can be deleted at any time by the operator; the Tool's access can also be revoked at any time from the Google account's security settings.
